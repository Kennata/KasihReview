# Aplikasi Kasih Review
Aplikasi ini adalah aplikasi pencarian film-film, pengulasan film, tempat untuk menyimpan daftar film-film yang akan ditonton, dan platform untuk berinteraksi dengan pecinta film lain.

Repository ini mengandung bagian Front end dari aplikasi ini, FE dibuat menggunakan Kotlin+Jetpack Compose, dan untuk mengatasi API Call ke BE digunakan Ktor

## ⚠️Dikarenakan BE dari aplikasi ini sudah non-aktif karena projek ini adalah projek untuk tugas besar kuliah, aplikasi ini tidak bisa dijalankan lagi
